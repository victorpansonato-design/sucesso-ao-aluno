# Comportamentos do aluno — lista para o onboarding

Tudo o que o aluno faz, ou deixa de fazer, que a gente poderia usar como sinal para agir.

A lista está aqui para ser cortada. Marque o que faz sentido, risque o que não faz, escreva o que falta.

São 81 comportamentos. O sistema já consegue enxergar 46 deles hoje. Outros 33 existem na vida do aluno e **não existem em lugar nenhum dos nossos dados** — esses estão marcados com "não" na coluna do meio, e cada um deles é um pedido de integração que alguém vai ter que fazer.
